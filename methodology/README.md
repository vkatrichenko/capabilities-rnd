# methodology/

The research-method log. **A deliverable, not a byproduct.**

Rodion Ugarov requires this so the process can be scaled to capabilities beyond AI SDLC security.
It is a first-class requirement of the project, not documentation added at the end.

`log.md` is the running record. Write to it **as work happens**. Each entry:

- what was attempted, and why that step came next
- which tool, command, or source was used
- what came back — including dead ends and negative results
- what was decided as a result

A method reconstructed after the fact is exactly what this requirement exists to prevent. Dead ends
are part of the method: a step that produced nothing is worth more to someone repeating the process
than a clean narrative that hides it.
